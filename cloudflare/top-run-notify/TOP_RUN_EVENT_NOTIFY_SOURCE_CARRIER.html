TOP RUN NOTIFICATIONS

iPhone用・通知サーバー統合ファイル

JS／Pythonを別々にダウンロードする必要はありません。以下のHTML 1ファイルに両方の元データを格納しました。

1

このHTMLを1つだけGitHubにアップロード

リポジトリ nuritakug-cpu/tabirun-bgm のブランチを top-run-notify-stage2-20261015 にして、次のフォルダへこのファイルをアップロードします。

cloudflare/top-run-notify/

ファイル名は TOP_RUN_EVENT_NOTIFY_SOURCE_CARRIER.html のまま変更しません。

2

GitHub Actions設定をコピー

ブランチを main に戻し、GitHubで .github/workflows/TOP_RUN_EVENT_NOTIFY_DEPLOY.yml を作成または編集して、下の内容を丸ごと貼り付けます。

iPhoneのファイル表示でコピー用ボタンが動かない場合は、このHTMLをSafariで開くか、コード欄を長押ししてコピーしてください。

3

事前検査だけ実行

GitHubの「Actions」から TOP RUN Event Notify deployment を選び、「Run workflow」の publish を OFF にして実行してください。

OFFの間は通知サーバーを公開しません。 本番更新には別途Firebaseサーバー側の権限確認が必要です。
