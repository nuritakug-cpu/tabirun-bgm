EVENT BASE 参加者入口

駅伝大会のEVENT BASEをSafariまたはChromeで開くための入口です。出走しない方もご利用いただけます。

LINE・BAND内では登録しないでください メッセージアプリから直接開くと、アプリ内のブラウザで表示される場合があります。
下のボタンでURLをコピーして、SafariまたはChromeから開いてください。
  1. 「EVENT BASEのURLをコピー」を押す
  2. LINE・BANDなどの画面を閉じる
  3. iPhoneはSafari、AndroidはChromeを開く
  4. アドレス欄に貼り付けて開く
  5. 以前利用した方は前回と同じブラウザで接続する。初めての方は画面の案内に沿って名前と6桁の参加番号を入力する
https://nuritakug-cpu.github.io/tabirun-bgm/EVENT_BASE_v81_EKIDEN_P47_CANONICAL_RACE_REHYDRATION_GUARD.html?event=eventbase_ekiden_dev_20261006&portal=1

コピーできない場合は、上のURL部分を長押ししてコピーしてください。

●起動に少し時間がかかる場合があります。 すぐに表示されなくても、そのままお待ちください。
●以前使ったことがある方は、同じSafari／Chromeから開いてください。情報が引き継がれる場合は、番号入力なしで接続できます。
●登録情報が違う・見つからない場合は、繰り返し登録せずクラブへお知らせください。
