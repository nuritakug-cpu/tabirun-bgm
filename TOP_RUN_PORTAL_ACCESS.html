TOP RUN PORTAL

PORTAL のご案内

このページは、案内です。
PORTALは、まだ開きません。下の ①〜⑤ の順番で、進めてください。

①PORTALのURLをコピーします

下のボタンを、押してください。

ボタンで、コピーできないときは、下のアドレスを、長押しして、コピーしてください。

②BANDを閉じます

BANDから、別のアプリに、切り替えます。（BANDは、そのままで大丈夫です）

③ブラウザを開きます

iPhoneは「Safari」（青いコンパスのアイコン）、
Androidは「Chrome」（赤・黄・緑の丸のアイコン）を、開きます。

④アドレス欄に貼り付けて、開きます

画面の「アドレスの欄」を押して、長押しします。「ペースト」（Androidは「貼り付け」）を押して、キーボードの「開く」（Androidは「→」「移動」「Go」）を押します。

開くまで、少し時間がかかります。止まったように見えても、そのまま、お待ちください。

⑤開けたら、先に「アイコン」を作ります

作りかたは、すぐ下の「アイコンの作りかた」を、見てください。

前の大会で、EVENT BASEのアイコンを作った方も、PORTALのアイコンは、新しく作ります。

ブラウザの画面では、登録しないでください。
登録は、アイコンができてから、そのアイコンから行います。
アイコンの作りかた

iPhone（Safari）

  1. 画面の右下の「…」を押して、「共有」を押します。
    （「…」が無い古いiPhoneは、画面の下にある、四角から上向きの矢印が出ているマーク「共有」を、直接押します）
  2. メニューを、指で上に引き上げて、下へスクロールします。
  3. 「ホーム画面に追加」（四角の中に＋のマーク）を押します。見つからないときは、一番下の「さらに表示」を押します。
  4. 名前が「TOP RUN」などになっているのを見て、右上の「追加」を押します。
  5. ホーム画面に、アイコンができたら、Safariを閉じます。

Android（Chrome）

  1. 画面の右上の「⋮」（点が縦に3つ）を押します。
  2. 「ホーム画面に追加」または「アプリをインストール」を押します。（機種によって、名前が違います。似た名前を探します）
  3. 確認の画面で、「追加」または「インストール」を押します。もう一度出たら、もう一度押します。
  4. ホーム画面（またはアプリの一覧）に、アイコンができたら、Chromeを閉じます。
アイコンができたら、ブラウザを閉じて、ホーム画面のアイコンを押して、開いてください。登録は、そのアイコンから行います。
前の大会で、EVENT BASEのアイコンを作った方へ

PORTALは、今回が、はじめての配布です。PORTALのアイコンは、全員、新しく作ります。

前の大会で作った、EVENT BASEのアイコンは、PORTALとは、別のものです。そのまま残して、大丈夫です。消さないでください。

EVENT BASEのアイコンを押しても、PORTALは、開きません。

うまくいかないときは、BANDで、運営に連絡してください。機種名と、画面の写真を、送ってもらえると、すぐ分かります。
登録は、1人1回だけです。2回登録しないでください。
