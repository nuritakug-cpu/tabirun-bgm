EVENT BASE 参加者入口

大会当日に使用するEVENT BASEを、SafariまたはChromeで開くための入口です。

BAND内では登録しないでください BANDから直接EVENT BASEを開くと、BAND内のブラウザで開く場合があります。
下のボタンでURLをコピーして、SafariまたはChromeから開いてください。
  1. 「EVENT BASEのURLをコピー」を押す
  2. BANDの画面を閉じる
  3. iPhoneはSafari、AndroidはChromeを開く
  4. アドレス欄に貼り付けて開く
  5. 名前と6桁の参加番号を入力して登録する
https://nuritakug-cpu.github.io/tabirun-bgm/EVENT_BASE_PRODUCTION.html?event=eventbase_mu4ujce3_xxx1&portal=1

コピーできない場合は、上のURL部分を長押ししてコピーしてください。

●登録後も、大会当日は登録した同じSafari／Chromeをご利用ください。
●位置情報は、登録しただけでは共有されません。
●位置共有は、大会当日に本人が「位置共有ON」を操作した場合のみ開始します。
