Firebase ローカル監査

Firebase JSONをこの端末のブラウザ内だけで解析し、個人情報を除去した監査結果だけを生成します。

このHTMLの安全条件

実データはChatGPT・Firebase・GitHub・その他のサーバーへ送信しません。 JSONはブラウザのメモリ内でのみ解析します。

外部通信禁止
Content Security Policyで connect-src を none に固定
Firebase未接続
Firebase SDK・APIキー・DB URLを一切使用しない
端末保存なし
localStorage / IndexedDB / Cookieを使用しない
個人情報を出力しない
氏名・CHAT本文・位置座標・自由記述は監査結果へ含めない

使い方

1
Firebaseから保存したJSONを選択iPhoneの「ファイル」アプリに保存した .json を選びます。
2
この端末内で監査UID / profileId / eventId / playerIdは U001 / P001 / E001 / A001 のように置換します。
3
匿名監査結果だけを共有「匿名結果をコピー」または「匿名JSONを保存」で生成した結果だけをChatGPTへ渡します。
まだJSONを読み込んでいません。
